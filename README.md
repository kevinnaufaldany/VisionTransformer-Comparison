# VisionTransformer-Comparison

## Indonesian Food Classification using Vision Transformers

Comparison of ViT, Swin Transformer, and DeiT models on custom Indonesian food dataset.

### Models
- Vision Transformer (ViT)
- Swin Transformer
- DeiT (Data-efficient Image Transformers)

### Dataset
- 5 food classes: bakso, gado_gado, nasi_goreng, rendang, soto_ayam
- 1108 total images (886 train, 222 val)
